# PhotoClock V2

Features:
- Full photo without cropping
- Blurred/dimmed background
- Multiple photo selection
- Crossfade slideshow
- 5s / 10s / 15s / 30s / 1m / 2m / 5m intervals
- Text size
- Text color
- Font selection
- Show/hide date
- Show/hide seconds
- Automatic / Portrait / Landscape orientation
- Screen stays awake
- Tap screen to show/hide controls
- Settings saved locally
